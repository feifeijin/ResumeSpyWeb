## Plan

Codebase findings (Vue 3 + Vuetify 3 + vue-i18n + vue-router, `src/`):
- The `v-toolbar__append` div is generated by Vuetify from the `#append` slot in
  `src/components/app/AppBar.vue:53`. Inside it, nav entries are rendered by
  `v-for="item in menu"` over the `menu` computed (`AppBar.vue:139`), each as a
  `<v-btn variant="text">` with an mdi icon. The same `menu` array also feeds the
  mobile navigation drawer.
- Content views (`HomeView`, `FaqView`, `ArticlesIndexView`) are NOT Vuetify —
  they are hand-rolled "noir" views: scoped CSS with `--bg/--surface/--border/
  --text/--muted/--gold-dim` tokens, `film-grain` overlay, breadcrumb, centred
  header (overline/title/subtitle), `grid-template-columns: repeat(auto-fit,
  minmax(280px, 1fr))` card grid, `useSeo()` for meta, all strings via i18n.
- Router (`src/router/index.ts`) uses static top-level imports + a flat `routes`
  array with `path` / `name` / `component`.
- Locales `src/locales/{en,zh,ja}.json` must stay key-identical
  (`npm run check:locales` enforces it).

Steps:
1. Add `navigation.tools` + a `tools` block (title/subtitle/metaDesc/comingSoon +
   the three tool names & one-line descriptions) to en/zh/ja.
2. New `src/views/ToolsView.vue` in the noir style: breadcrumb, header, responsive
   card grid; each card = rectangular image placeholder (hatched plate + glyph)
   above the tool name and one-line description, plus a "Coming soon" badge.
3. Register `/tools` (name `tools`) in `src/router/index.ts` with a static import.
4. Add a `Tools` entry to the `menu` computed in `AppBar.vue` so it renders inside
   the `#append` (= `v-toolbar__append`) block with identical `v-btn` styling.
5. Verify: `npm run check:locales`, `npm run type-check`, `npm run lint`. Commit.

Decisions:
- **Coming-soon state, not placeholder routes.** None of the three tools exist, so
  three stub routes/views would be dead weight and would leak into navigation and
  potentially the sitemap. Cards render as non-interactive `<article>` elements
  (`aria-disabled="true"`) with a "Coming soon" badge; swapping a card to a
  `<router-link>` later is a one-line change.
- **Tools added to the shared `menu` array** rather than as a one-off button. That
  array is what the append slot iterates, so the entry inherits the existing
  styling exactly; it also surfaces in the mobile drawer, avoiding a desktop-only
  nav item.
- **Not added to `scripts/generate-sitemap.mjs`** — the page has no real content
  yet, so indexing it would be thin content. Add it when the tools ship.
